# 斗鸡配表说明

策划维护 **斗鸡配置.xlsx**。已将当前游戏数据回填到工作簿：36个敌人、31个路线节点、44件装备、11套套装，以及剧情、弹幕和界面文本。旧工作簿曾落后于运行时JSON，本次已同步。

## 操作

1. 修改 Excel 第6行起的数据并保存。前5行分别是中文说明、字段名、类型、server_no、client，不要改动。
2. 在 Creator 打开 **扩展 → 斗鸡 Excel 配表**，点击 **校验预览** 检查各表记录与内容。
3. 点击 **导出并刷新资源**，成功后重新预览游戏。运行中的会话不会自动热更新。

首次安装时，在 **扩展 → 扩展管理器 → 项目** 刷新并启用 `chicken-excel`；列表未更新时重新打开项目。面板支持选择工作簿、打开Excel、错误提示和数据预览，怪物时长列位于名字旁边。详见 [扩展说明](../extensions/chicken-excel/README.md)。

命令行 `node tools/excel-kit.cjs` 和同目录的 **导出配置.bat** 仍可使用，二者与面板共用同一解析及校验逻辑。

导出到 `assets/bundle/config/game/*.json`，游戏加载这些文件。请勿手改JSON，它们会被下次导表覆盖。首次使用导表工具需要安装Node.js，并在tools目录运行 `npm ci`。

| Part | 染色色盘与可选表情 |

| Language | 动态界面文本和属性/招式名称，目前游戏使用zh列。保留文本里的{0}、{1}等占位符，可以调整顺序 |

| Stage | 旧流程兼容数据；当前玩法使用Route |

## 每只怪的目标战斗时长

修改 **Enemy.targetBattleSeconds**。默认普通怪25、正式赛Boss35、最终鸡王45，单位为秒。

这是节奏参考值：逻辑时间按 `GameRule.battle_referenceSeconds / targetBattleSeconds` 推进。目标增大时，双方攻击、回血、技能冷却和受击延迟一起变慢。仍然是血量归零结束，没有倒计时强制胜负；角色动作不被机械拉长。

例如，同一敌人由25改为50，纯逻辑验证中的耗时由约18.15秒变为36.29秒。**配置45并不保证实际打满45秒**，实际耗时取决于玩家强度、命中、复活、回血和动作时间。要提高Boss难度，请同时调整该怪的生命、攻防、速度和特殊能力；单独拉长时间只会改变节奏。

## 填写规则

- 数值必须为数字；int不接受小数；bool使用TRUE/FALSE或1/0。
- any填写合法JSON，例如随机名字池 `["小鸡大将","彩羽勇者"]`。
- 数值可选列留空表示未配置，显式0会保留；必填数值留空会报错。
- ID必须唯一；关卡、怪物、装备和套装引用必须存在。不要删除仍在使用或存档引用的ID。
- GameRule的desc/min/max用于说明，允许范围也由导表器校验，不能通过修改min/max绕过。
- 公式先在Excel里计算并保存；未计算或错误的公式缓存会阻止导出。
- 缺表、未知字段、重复ID、非法时长、错误引用和缺失占位符会阻止导出，在全部校验通过前不会覆盖任何JSON。
- 图片内烘焙文字、加载配置前的启动提示、角色动作及界面布局仍属于程序/美术资源。本表不修改图片中的文字。

## 程序验证

```
node tools/excel-kit.cjs
node tools/check-ts.cjs
node tools/run-verify.cjs
node tools/check-config.cjs
node tools/check-pace.cjs
```

check-config验证完整导出一致性、改表后的文案/地图/时长生效，以及非法数据阻断。check-pace按当前单怪配置验证节奏变化，不再使用固定45秒的Boss上限。脚本模拟不等同于Creator或真机观感验收。
