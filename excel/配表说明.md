# 斗鸡配表说明（关卡编辑器）

策划只改这一份 Excel：`excel/斗鸡配置.xlsx`。改完在项目根目录执行：

```
node tools/excel-kit.cjs
```

会按 oops 五列表头导出到 `assets/bundle/config/game/*.json`。游戏启动时读这些 json，不再写死数值。`Language` 也已并入同一份总表，不需要再维护单独的语言 Excel。

## 工作表

| 表 | 作用 |
| --- | --- |
| **Stage** | 旧版关卡表，仅供旧工具/旧存档兼容；当前流程以 Route 为准。 |
| **Route** | 当前固定路线：小怪 1 → 小怪 2 → 商店 → 小怪 3 → 商店 → 鸡王。`kind` 填 `battle` / `shop` / `boss`，战斗和鸡王节点填写 `enemyId` 与金币。 |
| **Enemy** | 敌人与鸡王。生命/攻防速度暴击、外观色、垃圾话。鸡王默认 id=`kun_boss`。 |
| **Player** | 玩家底板数值、名字、打鸡王金币、玩家垃圾话。`bossEnemyId` 指向 Enemy 表。 |
| **Part** | 开局染色色盘与表情。`type=color` 的 `value` 为色值；`type=face` 的 `value` 为 fierce/dumb/proud/cute。 |
| **Item** | 商店散件。数值列为空或 0 表示不加。外观件填 `isSkin=1`，可用 `skinFace` / `skinColor` 改形象。 |
| **Set** | 套装。`pieceIds` 必须是 JSON 数组字符串，如 `["iron_comb","iron_head"]`。2 件/4 件加成分列填写。 |
| **Reward** | 三选一部位强化池。`part` 填 `head` / `neck` / `body` / `wing` / `leg`；`maxLevel`、`scalePerLevel`、`weight` 控制部位等级、外观放大和出现概率。`part` 留空才是纯 buff（例如 `buff_gold`）。 |
| **Language** | 界面多语言文本。`id` 为语言 key，`zh` / `en` 直接填写对应文案。 |

## 表头规则（和 oops 转表插件一致）

前 5 行不要改结构：

1. 中文说明
2. 英文字段名（json 的 key）
3. 类型：`int` / `float` / `string` / `any`
4. `server_no`
5. `client`

第 6 行起才是数据。第一列 `id` 是主键，Enemy/Item/Set 用字符串，Stage/Player 用数字。

旧版 Excel 如果 Reward 仍是 `gold` / `atk` / `hp` / `def` / `spd` / `crit` 加 `randomPart` 列，`excel-kit.cjs` 会自动映射到当前 `buff_gold` / `up_*` 配置，并补齐新字段，不会导出成旧格式。

## 改关卡怎么做

1. 在 **Enemy** 加一只鸡（改数值和颜色）。
2. 在 **Route** 的 battle/boss 节点把 `enemyId` 填成这只鸡的 id，并设置胜负金币。
3. 跑 `node tools/excel-kit.cjs`，回编辑器刷新资源后预览。
