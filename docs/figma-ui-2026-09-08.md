# 鸡王争霸赛 UI 对接记录

设计来源：[Figma 鸡王争霸赛](https://www.figma.com/design/vUwHPgfiAPdheLudX6I7Uv/?node-id=75-433)。以 2026-09-08 补充的八张截图和讨论修改为准。设计图 1080×1920，项目保持 720×1280。

## 已接入

- 开始页使用带标题的原背景；点击开始进入“自定义你的专属战鸡”。五个染色部位、六种现有颜色，保留表情、随机名称和确认流程。
- 人物页移除左右属性格；左上返回，头、脖子、身体、脚、套装五页签。展示真实装备与强化等级；脖子暂无装备时显示空状态。
- 战前展示双方实际属性；战斗保留自动出招、碰撞判定和八种现有动作，增加滚动助威文案。
- 战斗结算台牌显示玩家名字；普通战斗按钮“选择强化”，前三选一确认后沿用原推进规则。
- 商店命名“鸡友杂货铺”；点击商品先查看介绍、金币价格和当前余额，确认后购买。商店弹出时下一战斗关已开放，顶部返回和底部“返回地图”均只关闭商店，不推进关卡。
- 五图分别为东篱村、青竹溪、金穗田、古祠镇、鸡王山。每图三个小怪关与一个 BOSS，共 20 个战斗关；另有每图两次商店弹出事件，保留原配表 ID。前四图 BOSS 胜利后“前往下一关”；第五图进入总结果。小怪失败停在原节点，BOSS 失败回到本大关第一小关；金币、装备、强化跨图保留。
- 地图只保留一个常驻的商店图标，不显示商店事件节点。小怪/BOSS 预览复用现有分部件战鸡；决战前商店使用村庄背景，其他时点使用商店背景。

## 本地存档与强化选择补充

- 强化默认不选中任何卡片；玩家点选后才能确认。移除跳过强化的逻辑入口。上限仍为 5 级，不足三项时展示剩余项，全满后不再发牌。
- 存档键为 `chicken_battle_save_v1`，通过 Cocos `sys.localStorage` 保存。一份 JSON 同时记录永久养成与关卡进度，避免金币和首通标记分开写入。
- 永久数据：金币、装备/套装所有权、当前穿戴、部位强化、额外属性、外观、名字、首通金币账本、已通关大关。
- 进度数据：当前节点、结算状态、原三张待选强化、固定货架、随机种子。结算、选择强化、购买、推进时立即保存；应用隐藏、浏览器 pagehide/beforeunload 以及返回首页时补存。
- 小关胜利时立即保存下一节点和待选强化；BOSS 胜利时立即标记大关通关、禁止再次挑战并保存下一大关起点。结算页按钮只切换界面，不负责推进或回退关卡。结算页直接退出也保留结果。
- BOSS 明确战败时立即把进度重置到本大关第一小关。永久数据和已领取金币记录不清除。沿用原战后强化发放规则，仍有可强化项时可选择一次强化再返回地图。
- 对局内没有“保存并退出”按钮。未分胜负时关闭游戏相当于没有打过本关，重新进入时从同一节点的战前准备重打，包括 BOSS；不保存战斗中的瞬时血量和动作，不发奖励，也不触发 BOSS 失败回退。
- 每个战斗节点仅首通发放金币，失败与重打已首通节点均不再发金币。退出强化页保留原选项，确认重复触发也不会重复升级或跳关。
- 首页提供“继续游戏”和“清除本地存档”。清除需在游戏弹窗中确认，删除本游戏全部养成与进度，不清除其他游戏或框架设置。总通关后的按钮返回首页，不再隐式重置养成。
- 新增存档/首通/三选一、结算自动推进和旧存档恢复检查后，逻辑用例共 32 项通过；游戏 TypeScript、18 个预制体及清档弹窗布局检查通过。浏览器/设备上的退出重开仍需实际验收。

## 装备穿戴补充

- 购买只增加背包所有权。在角色页点击单件或已集齐套装穿戴，再次点击卸下；同槽位替换，其他槽位保留。卡片标出穿戴状态。
- 属性和两件/四件套装加成只按实际穿戴计算，未穿戴装备不提供属性。切换时更新角色战力。
- 复用现有装备透明图片挂在对应角色部位下，随部位强化和战斗动作变化；脚部双鞋图分别显示左右半张。角色、备战、战斗与结算使用同一套显示逻辑。
- 穿戴记录随永久养成保存，BOSS 战败回退不清除。旧存档每槽默认穿上最后购买的一件；新存档的空穿戴列表保持为空。
- 逻辑用例增至 36 项，覆盖购买与穿戴分离、同槽替换、套装加成、外观快照、存档和战败保留；类型、预制体及穿戴规则下的战斗节奏检查通过。本地浏览器预览仍被 `ERR_BLOCKED_BY_CLIENT` 拦截，实际穿戴画面与动画尚未通过设备验收。

## 商店与关卡进度解耦

- 战斗胜利后跳过配表中的商店事件，立即保存下一战斗关；`shopPending` 仅记录强化完成后需要展示一次商店，不作为解锁条件。
- 地图常驻入口不限制访问关卡；重复进出商店、关闭或读档均不推进关卡，同一进度的已购货品不补货。
- 旧存档若停在商店行，读档时迁移到下一战斗关，并保留原购买、金币和货架；结算/强化未完成时仍保留商店弹出。
- 38 项逻辑用例、游戏类型、18 个预制体与战斗节奏检查通过；新增覆盖所有战斗关的商店开关/重开、10 个旧商店节点迁移和地图唯一商店入口。实际画面仍需 Creator/设备验收。
