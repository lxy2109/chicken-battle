# 斗鸡 Excel 配表

在 Cocos Creator 的 **扩展 → 斗鸡 Excel 配表** 打开面板。首次在 **扩展 → 扩展管理器 → 项目** 刷新并启用 `chicken-excel`；更新扩展后重新加载扩展，列表未更新时重新打开项目。扩展无需编译。

## 策划使用

1. 默认读取 `excel/斗鸡配置.xlsx`，可选择相同表结构的其他 `.xlsx`。
2. 选择工作表，在搜索框查询任意字段。完整读取所有记录，每页 50 条；Enemy 的目标战斗时长紧邻怪物名字。
3. 点击单元格直接编辑，支持多行文本。点击 **新增记录** 后填写字段；每行右侧固定的 **删除** 按钮可删除记录，确认后进入待保存状态。
4. 点击 **保存 Excel**，校验通过后写回原工作簿。错误会保留草稿，显示表名、单元格或 ID，修正后可再次保存。
5. 点击 **导出并刷新资源** 生成游戏 JSON，重新预览游戏生效。保存 Excel 和导出是两个独立操作；有未保存修改时会提示先保存。

切换工作簿、重新加载或关闭面板时，未保存修改需要确认放弃。保存失败不会清空草稿。Excel 被外部修改时会阻止覆盖，请先复制保留需要的草稿内容，再重新加载并重新修改。

数字按字段类型填写；布尔值填写 `true`/`false`，数组和对象填写 JSON。前五行表头、说明和字典页请在外部 Excel 中维护。公式单元格显示缓存结果且只读，含公式的行不能在面板删除；涉及公式依赖的修改，需要在 Excel 中重新计算并保存后再导出。

## 实现与验证

- 使用 `tools/config-workbook.cjs` 编辑原始行，保留真实 ID、未修改单元格、公式、表头和说明页。删除记录留空原行，避免移动其他行的公式坐标。
- 复用 `tools/config-export.cjs` 的类型、唯一 ID、引用和业务校验；已有错误数据仍可加载修正。
- 保存到同目录临时文件并重新校验，检查源文件版本后替换；失败时清理临时文件。Excel 占用文件导致失败时，关闭外部 Excel 后重试。
- ExcelJS/JSZip 依赖在 `tools`，首次运行 `npm ci`。导出目录固定为 `assets/bundle/config/game`。
- 该工具面向项目配置表，不是通用 Excel 排版或公式编辑器。

验证命令：

- `node tools/check-excel-crud.cjs`：真实工作簿增删改存、冲突保护、失败不覆盖、公式与未修改表保留。
- `node tools/check-excel-panel.cjs`：Creator 主进程接口及导出刷新模拟。
- `node tools/check-config.cjs`：导表和游戏配置回归。
- `node tools/check-excel-editor-ui.cjs`：浏览器操作面板并调用真实读写接口；需要 Playwright（可通过 `CHICKEN_PLAYWRIGHT_MODULE` 指定模块路径）和本机 Chrome。

浏览器模拟不等同于 Creator 内启用与交互验收。
